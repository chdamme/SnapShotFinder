Notations et limites de l’analyse automatique

Dom(f) est le domaine de définition : tous les x pour lesquels l’expression d’origine donne une valeur réelle. Im(f) est l’ensemble image : toutes les valeurs de y effectivement atteintes. Abscisse = x (axe horizontal) ; ordonnée = y (axe vertical).

ℝ désigne tous les nombres réels. ℝ \ {4} désigne tous les réels sauf 4. L’intervalle [a ; b] contient ses deux bornes ; ]a ; b[ ne contient aucune des deux. ∪ désigne la réunion et ∅ l’ensemble vide. Un cercle vide indique une valeur exclue.

−∞ et +∞ indiquent un prolongement sans borne dans la direction correspondante. Sur les bandes de Dom(f) et Im(f), ils accompagnent uniquement les flèches des parties non bornées. Une flèche seule indique une continuation hors du cadre, pas nécessairement jusqu’à l’infini. Ces symboles ne sont pas des graduations : le bord de la fenêtre représente toujours une valeur finie. L’infini n’est jamais une borne incluse.

L’application analyse les polynômes et les fonctions rationnelles de degré limité, ainsi que de nombreuses compositions avec sqrt, abs, ln, log, exp et les fonctions trigonométriques. Les calculs utilisent des nombres à virgule flottante ; ≈ indique une valeur arrondie. Pour les degrés très élevés, les valeurs extrêmes ou les compositions complexes, l’analyse globale est limitée. L’application indique alors « non déterminé intégralement » ou affiche seulement les conditions de définition. Elle ne déduit jamais un ensemble image global des seuls points échantillonnés à l’écran. Les racines recherchées numériquement concernent uniquement la vue affichée et leur liste peut être incomplète.

Les angles sont exprimés en radians. Les puissances fractionnaires, comme x^(1/3), sont interprétées dans les réels. 0^0 est considéré comme non défini dans cette application. Pour un exposant variable, comme dans x^x, le domaine réel n’est pas toujours déterminé intégralement.
